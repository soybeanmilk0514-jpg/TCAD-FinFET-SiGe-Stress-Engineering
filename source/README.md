# Source Code Scope

## Why the Sentaurus Deck Is Not Included

The baseline device was derived from a Synopsys Sentaurus Applications Library FinFET example.

The original team repository intentionally did not redistribute the full SProcess / SDevice / SVisual example scripts because they are proprietary Synopsys materials. This personal portfolio follows the same rule.

## What Is Publicly Documented Instead

- baseline geometry and electrical conditions
- Ge and FR design-of-experiments range
- extracted stress and electrical metrics
- STE definition
- individual and team result CSV files
- analysis workflow and validation logic
- final trade-off and design-window interpretation

## Team Analysis Code

The team Share repository contains Python utilities used to merge exported data, calculate STE/DIBL, and generate figures.

Those scripts are team collaboration artifacts and are not copied here as if they were my individual code.
